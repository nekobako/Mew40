# Mew40
A low-profile, unibody keyboard with a 40% ortholinear layout.

![Mew40 CNC](https://github.com/user-attachments/assets/e11f1d2c-5bf5-4357-8b3e-9557975db8ec)

![Mew40 3DP](https://github.com/user-attachments/assets/d43aca9b-c387-4b3c-835a-97d617de1f68)

## Key Features
- 48-key ortholinear layout arranged in 4 rows of 12 keys
- Hot-swappable 3-pin switches compatible with Choc V2
- Full color backlighting for every key
- Choice of an aluminum case machined by CNC or a resin case made with 3D printing
- Keymap customization with Vial
