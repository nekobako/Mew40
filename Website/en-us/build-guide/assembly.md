# Assembly
Install the switches and keycaps on the top case and main PCB, then mount the USB port adapter on the bottom case.

## Installing the Switches and Keycaps
1. Place the main PCB against the underside of the top case, align the parts, and insert a switch at each corner.

![Installing the Switches and Keycaps](/images/build-guide/assembly/0.png)

2. Insert the remaining switches in the same way.

![Installing the Switches and Keycaps](/images/build-guide/assembly/1.png)

3. Install the keycaps on the switches.

![Installing the Switches and Keycaps](/images/build-guide/assembly/2.png)

## Installing the USB Port Adapter
1. Position the USB port adapter against the posts on the bottom case.

![Installing the USB Port Adapter](/images/build-guide/assembly/3.png)

2. Secure it with the pan-head screws (M2 × 3 mm).

![Installing the USB Port Adapter](/images/build-guide/assembly/4.png)

3. Connect the RP2040-Tiny on the main PCB to the USB port adapter with the included FPC cable.

![Installing the USB Port Adapter](/images/build-guide/assembly/5.png)

::: warning Caution
With the connector cover open, check the FPC cable orientation and insert it straight in as far as it will go.  
After that, make sure the cover closes fully without force.

For details, see the Cable Connection section of the [Waveshare Wiki](https://www.waveshare.com/wiki/RP2040-Tiny).
:::

::: info Information
Leave the top and bottom cases unsecured for now; you will need to press the button on the USB port adapter when flashing the firmware.
:::
