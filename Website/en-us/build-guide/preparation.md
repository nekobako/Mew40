# Preparation
Gather the required parts and tools, then separate the breakaway tabs from the main PCB.

## Parts Included in the Kit
| Part | Quantity | Notes |
| --- | ---: | --- |
| Main PCB | 1 | Diodes and LEDs are pre-installed |
| Top case | 1 | Aluminum or resin |
| Bottom case | 1 | Aluminum or resin |
| Pan-head screws (M2 × 3 mm) | 4 | To secure the USB port adapter |
| Hex-socket flat-head bolts (M3 × 8 mm) | 4 | To secure the top and bottom cases |

![Parts Included in the Kit](/images/build-guide/preparation/0.png)

## Parts to Prepare Separately
| Part | Quantity | Notes |
| --- | ---: | --- |
| RP2040-Tiny | 1 | Use the version bundled with the USB port adapter |
| USB Type-C cable | 1 | |
| Kailh Choc switch sockets | 48 | |
| Kailh Choc V2 compatible switches | 48 | 3-pin type (one center post and two metal pins) |
| Low-profile keycaps (1U) | 48 | Compatible with the switches above |
| Rubber feet | Optional | |

![Parts to Prepare Separately](/images/build-guide/preparation/1.png)

::: warning Caution
The RP2040-Tiny is also sold without the USB port adapter.  
Make sure to select the right version.
:::

::: warning Caution
Switches with four pins (one center post and three metal pins) are not compatible: both the pin count and the height of the plate section differ.  
Make sure to select the right version.
:::

## Separating the Breakaway Tabs
1. Use pliers to break off the tabs at the top and bottom of the main PCB along the perforated lines.

![Separating the Breakaway Tabs](/images/build-guide/preparation/3.png)

2. File the remaining edges until they are reasonably flat.

![Separating the Breakaway Tabs](/images/build-guide/preparation/4.png)
