# Soldering
Solder the switch sockets and RP2040-Tiny to the main PCB.

## Soldering the Switch Sockets
1. Apply solder to one of the pads for each switch socket in advance.

![Soldering the Switch Sockets](/images/build-guide/soldering/0.png)

::: warning Caution
The pre-installed LEDs on the main PCB are heat-sensitive, so take care not to overheat them while soldering.
:::

2. Fit each switch socket onto the PCB, aligning it with the orientation shown by the silkscreen.

![Soldering the Switch Sockets](/images/build-guide/soldering/1.png)

::: warning Caution
The orientation of Kailh Choc switch sockets can be confusing, so check it carefully before soldering.
:::

3. Hold the socket down with tweezers and melt the solder on that pad again to secure it.

![Soldering the Switch Sockets](/images/build-guide/soldering/2.png)

4. Solder the other pad to secure the socket.

![Soldering the Switch Sockets](/images/build-guide/soldering/3.png)

5. Repeat these steps for all switch sockets.

![Soldering the Switch Sockets](/images/build-guide/soldering/4.png)

## Soldering the RP2040-Tiny
1. Position the RP2040-Tiny on the pads provided for it on the main PCB.

![Soldering the RP2040-Tiny](/images/build-guide/soldering/5.png)

2. Apply flux to the pads and castellated through-holes.

![Soldering the RP2040-Tiny](/images/build-guide/soldering/6.png)

3. Solder each pad, one at a time, to secure the RP2040-Tiny.

![Soldering the RP2040-Tiny](/images/build-guide/soldering/7.png)

::: info Information
To make soldering the first pad easier, hold the RP2040-Tiny in place with masking tape or similar.
:::
