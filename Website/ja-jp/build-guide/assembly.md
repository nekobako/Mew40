# 組み立て
トップケースとメイン基板にスイッチとキーキャップを取り付け、ボトムケースに USB ポートアダプタを取り付けます。

## スイッチとキーキャップの取り付け
1. トップケースの裏側にメイン基板をあてがい、位置を合わせて四隅のスイッチを差し込みます。

![スイッチとキーキャップの取り付け](/images/build-guide/assembly/0.png)

2. 同様に残りのスイッチも差し込みます。

![スイッチとキーキャップの取り付け](/images/build-guide/assembly/1.png)

3. スイッチにキーキャップを取り付けます。

![スイッチとキーキャップの取り付け](/images/build-guide/assembly/2.png)

## USB ポートアダプタの取り付け
1. ボトムケースの突起に合わせて USB ポートアダプタを配置します。

![USB ポートアダプタの取り付け](/images/build-guide/assembly/3.png)

2. なべ小ねじ (M2 × 3 mm) で固定します。

![USB ポートアダプタの取り付け](/images/build-guide/assembly/4.png)

3. メイン基板の RP2040-Tiny と USB ポートアダプタを付属の FPC ケーブルで接続します。

![USB ポートアダプタの取り付け](/images/build-guide/assembly/5.png)

::: warning 注意
FPC ケーブルは裏表に注意し、コネクタのカバーが開いた状態でまっすぐ奥まで差し込んでください。  
その後、カバーが無理なく完全に閉まることを確認してください。

詳しくは [Waveshare Wiki](https://www.waveshare.com/wiki/RP2040-Tiny) の Cable Connection の項目を参照してください。
:::

::: info 情報
ファームウェアを書き込む際に USB ポートアダプタのボタンを押す必要があるため、ここではまだトップケースとボトムケースを固定しません。
:::
