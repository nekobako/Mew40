# 準備
必要な部品と工具類を用意し、メイン基板の捨て板を切り離します。

## キットに含まれる部品
| 部品 | 数量 | 備考 |
| --- | ---: | --- |
| メイン基板 | 1 | ダイオードや LED は実装済み |
| トップケース | 1 | アルミ製または樹脂製 |
| ボトムケース | 1 | アルミ製または樹脂製 |
| なべ小ねじ (M2 × 3 mm) | 4 | USB ポートアダプタの固定用 |
| 六角穴付き皿ボルト (M3 × 8 mm) | 4 | トップケースとボトムケースの固定用 |

![キットに含まれる部品](/images/build-guide/preparation/0.png)

## 別途用意が必要な部品
| 部品 | 数量 | 備考 |
| --- | ---: | --- |
| RP2040-Tiny | 1 | USB ポートアダプタ付属のもの |
| USB Type-C ケーブル | 1 | |
| Kailh Choc スイッチソケット | 48 | |
| Kailh Choc V2 互換スイッチ | 48 | 3 ピン (中央の突起 + 金属ピン 2 本) のもの |
| ロープロファイルキーキャップ (1U) | 48 | 上記スイッチに対応するもの |
| ゴム足 | 任意 | |

![別途用意が必要な部品](/images/build-guide/preparation/1.png)

::: warning 注意
RP2040-Tiny は USB ポートアダプタが付属しない単体版も販売されています。  
誤って購入しないようご注意ください。
:::

::: warning 注意
4 ピン (中央の突起 + 金属ピン 3 本) のスイッチはピン数とプレート部分の高さが適合しません。  
誤って購入しないようご注意ください。
:::

## メイン基板の捨て板の切り離し
1. メイン基板の上下に付いている捨て板を、点線に沿ってペンチで折って切り離します。

![メイン基板の捨て板の切り離し](/images/build-guide/preparation/3.png)

2. 残った縁がある程度平らになるよう、やすりがけをします。

![メイン基板の捨て板の切り離し](/images/build-guide/preparation/4.png)
