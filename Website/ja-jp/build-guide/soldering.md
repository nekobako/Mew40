# はんだ付け
メイン基板にスイッチソケットと RP2040-Tiny をはんだ付けします。

## スイッチソケットのはんだ付け
1. メイン基板のスイッチソケット用のパッドの片方に予備はんだを盛ります。

![スイッチソケットのはんだ付け](/images/build-guide/soldering/0.png)

::: warning 注意
メイン基板に実装済みの LED は熱に弱いため、はんだ付け中に過熱しないようご注意ください。
:::

2. スイッチソケットをシルク印刷の向きに合わせてはめ込みます。

![スイッチソケットのはんだ付け](/images/build-guide/soldering/1.png)

::: warning 注意
Kailh Choc スイッチソケットは向きが紛らわしいため、はんだ付け前によく確認してください。
:::

3. ピンセットで上から押さえながら予備はんだを溶かして固定します。

![スイッチソケットのはんだ付け](/images/build-guide/soldering/2.png)

4. 反対側のパッドにもはんだを流し込んで固定します。

![スイッチソケットのはんだ付け](/images/build-guide/soldering/3.png)

5. すべてのスイッチソケットに対して上記の手順を繰り返します。

![スイッチソケットのはんだ付け](/images/build-guide/soldering/4.png)

## RP2040-Tiny のはんだ付け
1. メイン基板の RP2040-Tiny 用のパッドに合わせて RP2040-Tiny を配置します。

![RP2040-Tiny のはんだ付け](/images/build-guide/soldering/5.png)

2. パッドと端面スルーホールにフラックスを塗布します。

![RP2040-Tiny のはんだ付け](/images/build-guide/soldering/6.png)

3. 1 か所ずつ、すべてのパッドにはんだを流し込んで固定します。

![RP2040-Tiny のはんだ付け](/images/build-guide/soldering/7.png)

::: info 情報
RP2040-Tiny が動かないようマスキングテープなどで固定することで、最初のパッドがはんだ付けしやすくなります。
:::
